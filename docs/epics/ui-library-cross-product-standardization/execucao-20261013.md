## Decisões de não migração

R18 ConversationListItem: Admin tem duas identidades/contagens e wrap, Teacher compacto; compartilhar row exigiria muitas adaptações ou props. R24 assinatura Admin: seis colunas e grids intermediários, hierarquia/click target distintos de OperationalList; CSS atual também atende outras tabelas. Mantidos separados, com discoveries documentados. R13 já havia sido adiada pelo mesmo critério de custo-benefício.
