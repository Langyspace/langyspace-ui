# Quizzes de gramática — revisão86

Problema: os31 quizzes preparados avaliam sobretudo recuperação de informação, frequentemente repetindo a resposta no contexto. A usuária pediu refazer o planejamento e as questões para praticar como escrever/falar corretamente.

Objetivo:31 quizzes de6 decisões gramaticais, vinculadas ao conteúdo de cada aula, com alternativas plausíveis e explicação curta. Mesmos componentes e IDs de atividades. Escopo: autoria dos186 itens, prévias no encerramento, guideline e evidência de revisão. Flashcards, Shadowing, mídia, progresso e publicação remota ficam preservados.

Critérios: cada item testa uma regra identificada; uma única resposta defensável; enunciado não entrega a resposta; contexto só quando necessário; nível e tema coerentes; exemplo da prévia é o mesmo do Student.
