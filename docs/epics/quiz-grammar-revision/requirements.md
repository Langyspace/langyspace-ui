# Requisitos

- Preservar31 atividades,6 questões cada e120 atividades no lote total
- Priorizar escolha entre duas realizações da mesma frase; usar erros verossímeis de auxiliar, concordância, ordem, tempo, complemento ou conector
- Alternar reconhecimento da construção correta, correção de frase e decisão de forma pelo sentido. Não usar definição/interpretação nem alternativas de assuntos diferentes
- Não chamar uma variante válida de errada. Se ambas as formas existirem, contexto precisa excluir uma interpretação explicitamente; preferir erro de forma para evitar ambiguidade
- Cada feedback explica a regra e apresenta uma forma correta, sem repetir apenas Exactly/Check the context
- A1/A2: frases curtas e léxico já aprendido. B1/B2: auxiliares, aspecto, subordinação e padrões. C1: forma das construções avançadas e registro sem julgar informalidade como erro
- Correção gramatical do dever não substitui compreensão, diálogo ou conversa livre da aula
- Sem duplicar/regenerar mídia, modificar progresso, publicar atividades ou habilitar links sem recibos
