# Tarefas por dependência

Cada tarefa tem arquivo próprio em tasks/. Uma única tarefa fica em execução; checks e decisões são atualizados antes da próxima. Avançar continuamente sem parar por componente.

- [x] 01 Inventário completo e fatos dos consumidores
- [x] 02 Padrão de leitura, revisão crítica e exemplos de referência
- [x] 03 Foundations, tokens e receitas internas
- [x] 04 Ações, campos e formulários
- [x] 05 Autenticação, marca e documentos
- [x] 06 Estados, superfícies, dados e métricas
- [x] 07 Navegação, overlays e mensagens
- [x] 08 Calendário e prática
- [x] 09 Simplificação comprovada dos consumidores
- [x] 10 Documentação completa, pacote e PRs com evidências
- [ ] 11 Aprovação humana, integração/publicação autorizada e encerramento

O objetivo permanece aberto enquanto qualquer critério obrigatório estiver pendente. A preparação de PRs pode ficar pronta com revisão humana pendente; isso não autoriza merge nem conclui publicação.
