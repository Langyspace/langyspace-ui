# Developer English — Your first day on the team

Current revised plan, 24 November 2026. B1 reference, 11 pages / 50 minutes. This version supersedes the Save draft narrative in the archived source plan and early meeting notes.

**Shared-screen delivery:** the learner speaks; the teacher operates the visual prototypes. No classroom typing task or learner audio recording.

**Concrete project:** a customer portal. Owen owns Registration, Ruby owns Password reset, Priya owns the account backend, Niamh checks behavior, Kim facilitates and helps. The learner owns the Login screen: email, password, Sign in, wrong-password message and Forgot password link. Existing portraits/voices reused; all work roles are fictional scenario assignments.

Planning has six teammate turns and six live replies. Review is a sequence of concrete presentations, not a dialogue padded to meet a turn quota. The review includes three colleagues because the revised narrative explicitly connects registration, recovery and backend before the learner’s Login presentation. No learner answers are synthesized or graded as a single correct personal response. Optional hints support function and language.

The first prototype is prepared exercise evidence, not code the learner is expected to create during class. Demo buttons make local state changes only. No repository actions, account creation, external messages or progress writes occur. Homework has native previews plus two verified staging destinations:20 flashcards and6 shadowing phrases. Production destinations remain disabled; the lesson itself is still in local review.
