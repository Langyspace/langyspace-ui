  it does not silently rewrite unrelated existing lessons.

## Source-grounded diagnosis

The old viewport combined JS-controlled steps with mandatory CSS snap and smooth scrolling.
The current wheel detector could also rearm on two small rising packets after a decaying tail.
Both are plausible contributors to the reported late extra page. The browser specification requires
reevaluating snap after layout changes; this does not itself prove which path occurred on the user’s
trackpad. No reproduction/browser measurements are claimed in this delivery.

References: [CSS Scroll Snap specification](https://www.w3.org/TR/css-scroll-snap-1/#re-snap)
and [MDN wheel cancelability](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event).
The implementation uses source analysis and the user’s report; final physical trackpad review is human-owned.
