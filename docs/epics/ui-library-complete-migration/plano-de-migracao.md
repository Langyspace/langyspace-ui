Prioridade é remover a segunda pele reutilizável com pequenas concessões, preservando estrutura/experiência. Não converter hero, tabela operacional ou card de plano rico para reduzir linhas. Concessões de contraste6b, foco comum, sombra/radiusCupom, CEFR sólido e alinhamento lacuna Teacher são explícitas em mapeamento.md. Nenhuma muda informação, política financeira ou acesso.

Critérios para fechar preparação: contrato sem flags de produto; composição React explícita; attrs/ref/teclado preservados; nenhum serviço domínio UI; manifest+API+package atuais; adoção real nos callsites; matrizes completas de rotas/estados/widths; instruções e PRs uniformes em tabela. Critério adicional de integração: product owner aprova a revisão de cada PR. Produção exige fluxo staging verificado e publicação/readback autorizados.
