# Mapeamento final do estado atual

Data: 2026-10-14. Baselines exatos em [baselines.json](baselines.json). Inventário da preparação; implementação, aprovação humana, integração e publicação concluídas em 2026-10-15, conforme [entrega.md](entrega.md). Este documento substitui as decisões preliminares dos38 grupos, sem afirmar publicação.

Os cinco produtos são Site, Admin, Cupom, Student e Teacher. “Sem correspondente” não significa uma tarefa para inventar componente naquele produto. A UI fornece contratos React; páginas, models, routing, fetching, stores e regras de negócio ficam nos consumidores.

V0: troca de owner sem mudança de geometria pretendida. V1: concessão pequena de cor/borda/foco/alinhamento, sujeita à review humana. V2: mudança de hierarquia/grid/densidade/scroll/interação; compartilhar partes menores ou conservar composição. Não há estimativa de economia em horas. Contagens estáticas não provam callsites nem comportamento.

## Limite crítico da migração

Módulos de página ainda possuem styled-components para grid, visibilidade, scroll e medidas. Isso é esperado. Coincidências de3–6 linhas de CSS não justificam publicar Row/Stack/List sem significado. Os wrappers que apenas delegam a owner UI também aparecem como duplicação sintática e não duplicam sua implementação. MetricTile/Surface variants de demo Admin, AuthDeliveryBadge sem uso e cópias fora do runtime não entram como componentes de produção.

As partes mantidas locais estão nomeadas acima: hero/sections editoriais Site, shell chrome e bridges Router, plano rico Student, fila/tabela e workflow financeiro Admin, cálculo/fuso/seleção de agenda Teacher, conteúdo/formatação/domain de todos. Manter esses containers não é deixar uma segunda implementação da apresentação compartilhada. [Inventário residual](residuos.md) explica cada coincidência restante.

Os valores locais de progresso, ordenação, clipboard, pix/checkout, recurrences, áudio e completion não são responsabilidade UI. Nenhum dado real, backend ou provider foi alterado nesta migração.
